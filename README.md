There are three python notebook as follows - 

1. NA-MSCT-Net_SisFall_Multi_Class containing the python code for noise aware multi-scale CNN-Transformer network for multi-class fall detection on SisFall Datasets.
2. NA-MSCT-Net_MobiFall_Multi_Class containing the python code for noise aware multi-scale CNN-Transformer network for multi-class fall detection on MobiFall Datasets.
3. NA-MSCT-Net_SBinary_Class containing the python code for noise aware multi-scale CNN-Transformer network for multi-class fall detection on both SisFall and MobiFall Datasets. 


Note: All the experiments were performed on online Python notebook (Kaggle) with persistence and acceleration capabilities, integrated with 28 GiB of RAM and an NVIDIA Tesla P100 16 GiB GPU for tensor-core computation (Keras and TensorFlow) and analysis.
